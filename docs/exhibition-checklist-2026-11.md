# 졸업전시 당일 체크리스트 (2026-11-04)

시연 기기 = 스마트폰 1대(시연용) + 전시장 Cube QR. 시연 흐름은 **비로그인**이다.

## 시작 전 (각 기기 1회)
- [ ] 시크릿 창이 아니라 **일반 창**에서 `https://www.gonggancube.com/demo-shot` 접속 → HOME으로 돌아옴
  - 이 브라우저에서만: HOME 「엄선한 공간」 맨 앞에 아카커피룸 + 비로그인 **저장 버튼이 로그인 대신 즉시 표시**됨 (DB에는 저장 안 됨)
  - **관람객이 바뀔 때마다** 이 주소를 다시 열면 저장 표시가 비워진다 (= 초기화)
- [ ] HOME 정상 로딩, 이미지 깨짐 없음
- [ ] 공간 둘러보기 → 아카커피룸 / 녹화버튼 / 턴다운서비스 상세가 열림
- [ ] 저장 버튼 → 즉시 "저장됨" (로그인 화면으로 가면 `/demo-shot`을 안 거친 것 → 다시 접속)

## QR (실제 인쇄본 스캔)
| 공간 | Cube | 직접 주소 |
|---|---|---|
| 아카커피룸 | GC-001 | `/c/GC-001` |
| 턴다운서비스 | GC-004 | `/c/GC-004` |
| 녹화버튼 | GC-006 | `/c/GC-006` |

- [ ] 스마트폰 기본 카메라로 Cube QR 스캔 → 로딩 후 **EP.1**이 바로 열림 (로그인 요구 없음)
- [ ] Scene 5장 끝까지 이동
- [ ] 「방명록 열기」→ 방명록 캔버스(로그인 없음)
- [ ] 포스트잇 작성 → 저장 → 캔버스에 바로 보임 (닉네임은 "익명의 방문자")
- [ ] HOME 복귀 → 두 번째 시연 반복

## 알아둘 동작 (버그 아님)
- 한 방문자(같은 브라우저, 12시간) = **포스트잇 1개**. 같은 폰으로 두 번째 시연을 하면 "이미 남겼어요" 상태가 된다.
- QR 접근은 12시간 유효. 같은 폰에서 QR을 다시 스캔해도 정상 진입.
- 실제 방명록에 쓴 시연용 포스트잇은 관리자 → 방명록 페이지에서 숨김/삭제할 수 있다.

## 문제가 생기면 (Fallback)
| 증상 | 바로 할 일 |
|---|---|
| 저장 버튼이 로그인으로 감 | `/demo-shot` 접속 후 HOME에서 다시 시작 |
| 포스트잇이 "이미 남겼어요" | 다른 브라우저/기기, 또는 시크릿 창으로 QR 다시 스캔 (새 방문자로 인식) |
| QR 인식 안 됨 / 오류 | 주소창에 `gonggancube.com/c/GC-001` 직접 입력 |
| 방명록이 "준비 중" | 관리자 → 해당 공간 방명록 세션이 ACTIVE인지 확인 |
| 네트워크 불량 | 휴대폰 핫스팟으로 전환 후 새로고침 |
| 화면이 멈춤 | 새로고침. 그래도 안 되면 `/demo-shot` 재접속 |
| 전시 종료 후 | `/demo-shot?off=1` 로 시연 표시 해제 |

## 시연 중 건드리지 말 것
- 관리자 로그인 상태로 시연하지 말 것 (관리자 행동은 KPI에서 제외되고, 잠금도 우회되어 일반 방문자 화면과 다르다).
- 실제 Partner 공간 · Cube · Episode · 기존 방명록은 수정/삭제 금지.
