# Handoff — 졸업전시용 운영자 KPI 시뮬레이션 (2026-11-03)
- **무엇**: 졸업전시(2026-11-04)에서 분석 기능을 보여주기 위한 **표시 전용** QR 스캔 시뮬레이션. DB 쓰기 0 — SpaceScan · SpaceKPI · SpaceMonthlyReport · Record · 방명록 무변경, 월간 리포트/추천/집계 코드는 이 모듈을 import하지 않는다(import 하는 곳은 아래 관리자 화면 2곳뿐).
- **대상**: `isActive && !isDemo` 운영 공간 중 아카커피룸 제외 5곳(북눅 연남 · 내면의 발견 · 턴다운서비스 · 다시점 · 녹화버튼). 아카커피룸은 시뮬레이션에 없고 실데이터(최근 30일 43회 확인) 그대로. 카페 공간(buk, 영구 시연 공간)은 운영 공간이 아니라 대상 아님.
- **값**: `src/lib/kpiSimulation.ts`(순수 함수, 고정 seed `gradshow-2026-11-04`). 공간별 30일 합계는 15~30 순열 배정(5곳 모두 서로 다름: 19 · 28 · 16 · 18 · 25), 날짜별 분산은 합계 정확히 보존·0건인 날 포함·최근으로 갈수록 약간 증가. 같은 입력이면 항상 같은 값(새로고침/재배포 불변), 공간이 추가·삭제되면 배정이 달라질 수 있다. 오늘(KST) 포함 최근 30일.
- **접근**: 켜는 길은 관리자 전용 `POST /api/admin/kpi-simulation {enabled}`(httpOnly 쿠키 `sc_kpi_sim`, 12시간 후 자동 해제)뿐이고, 읽을 때(`kpiSimulationServer.getKpiSimulation`)도 **현재 세션이 관리자인지 다시 확인**한다 → URL 파라미터로는 불가, 쿠키를 위조해도 비관리자는 항상 실데이터. 운영자(/operator)는 원래 KPI 화면이 없다.
- **화면**: `/admin/reports` — 상단 "졸업전시 시연 모드 켜기/끄기" 버튼 + "시연 데이터" 배너, 공간 표의 30일 QR 스캔이 시연 대상 공간만 값+"시연" 뱃지로 바뀜(아카커피룸 등은 실제 값). `/admin/[id]/report` — 같은 토글/배너 + 시연 QR 섹션(합계 · 30일 일별 추이 막대 · 공간별 비교 막대 · 계산 근거 문구). 아카커피룸 페이지는 "실데이터" 안내만. 기존 실제 KPI 섹션·리포트 미리보기(PDF)는 **그대로**이며 시연 값이 섞이지 않는다.
- **시뮬레이션하지 않은 것(의도)**: 스토리 조회 · 완독 · 체류시간 · 방명록 · 취향 · 재방문 · 퍼널 · Record 기반 일별 추이. 실제 기록이 없는 지표를 지어내지 않기 위해 실제 값 그대로. 서비스 전체 흐름(A/B 퍼널)과 Overview(/admin) 합계도 실제 값.
- **검증(읽기 전용 DB)**: 결정성 true · 5곳 모두 합계=일별 합 · 30일 · 15~30 · 아카커피룸 미포함 · SpaceScan 전체 476행 조회만(변경 없음). tsc · eslint(변경 파일) · vitest 1121(신규 3) · build 통과.
- **미검증**: 관리자 로그인이 필요한 실제 화면 렌더(브라우저 확인 불가 — 배포 후 /admin/reports에서 토글 확인 필요). 해제 후 실데이터 복귀는 쿠키 삭제 + 분기 코드(null이면 기존 경로)로만 확인.
- **전시 후**: 쿠키가 12시간 만료되므로 별도 정리 불필요. 완전히 없애려면 위 파일 5개와 두 페이지의 sim 분기를 지우면 된다. `reportDateRange.addDays`를 export로 바꾼 것만 기존 파일 변경.
